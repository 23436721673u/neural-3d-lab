# NEURAL·3D · 神经网络实时 3D 可视化实验室

不依赖任何机器学习框架，用原生 JavaScript 从零实现多层感知机（MLP），并用 Three.js 在 3D 空间中实时展示神经网络的训练过程。

## 功能

- **手写前向 / 反向传播**：tanh 隐藏层 + sigmoid 输出 + 交叉熵损失，链式求导全部手动实现
- **从零实现 Adam 优化器**：一阶 / 二阶动量与偏差修正；学习率按对数刻度实时可调，隐藏神经元数量可调
- **4 类非线性数据集**：螺旋、圆环、异或、双簇；可用鼠标点击添加样本或清空数据
- **3D 可视化**：网络结构（神经元激活强度、权重流动）、3D 决策曲面，以及实时 Loss / 准确率曲线

## 运行

单个 HTML 文件，用 Chrome / Edge 直接打开 `index.html` 即可（需要联网加载 Three.js）。

## 技术栈

JavaScript · Three.js · WebGL · Canvas
